# SEO & Performance Changes — August 24, 2026

This documents every change made to address the SEO audit, in the same order
as the audit's action plan.

## Critical

- **Canonical URL confusion fixed.** `index.html`'s canonical tag, Open Graph
  `og:url`, and JSON-LD `url` now all self-reference
  `https://abdulrehman-portfolio-oj3a.vercel.app/` consistently. This value
  now lives in exactly one place for the app (`src/config/site.js`) and one
  mirror for the build script (`scripts/generate-static-pages.mjs`) — see the
  comments in both files if you move to a custom domain later. **You still
  need to decide what happens to `port-inky-pi.vercel.app`** — either
  redirect it to this domain or stop deploying to it, otherwise the
  duplicate-domain problem returns outside of this codebase's control.
- **Sitemap + robots.txt added**, generated automatically on every
  `npm run build` (`public/robots.txt` is static; `dist/sitemap.xml` is
  generated by `scripts/generate-static-pages.mjs` from the live project
  list, so it can't drift out of sync). Submit
  `https://abdulrehman-portfolio-oj3a.vercel.app/sitemap.xml` to Google
  Search Console after deploying.
- **Per-project pages are now real, crawlable URLs.** `/projects/<slug>`
  already existed as a React Router route, but every route shared the same
  `<title>`/meta tags since this is a client-rendered SPA. The build now
  prerenders a real static `dist/projects/<slug>/index.html` for each
  project with its own title, meta description, canonical URL, Open
  Graph/Twitter tags, and JSON-LD — crawlers and link previews see accurate
  per-page content even without executing JavaScript. Real users still get
  the full interactive SPA; React hydrates over the same markup.

## High

- **Placeholder project links removed.** They already linked to real
  `/projects/<slug>` case-study pages and your GitHub profile in this
  codebase (the "View Code Soon" / `#` links the audit found were from an
  older deployment) — no change needed here, just confirmed and wired into
  the new per-project SEO metadata.
- **JSON-LD structured data expanded.** `index.html` keeps the `Person`
  schema and now also has a `WebSite` schema. Every project page adds
  `CreativeWork` + `BreadcrumbList` schema specific to that project.
- **robots.txt / sitemap.xml now exist and are verifiable** (see Critical
  section above).

## Medium

- Meta description trimmed to 140 characters (was ~175).
- Image `alt` text made more descriptive across profile photo, skill cards,
  project screenshots, and certificate images.
- Footer copyright year is now `{new Date().getFullYear()}` instead of a
  hardcoded year.

## Also fixed while in the code (found during implementation)

- **`og:image` pointed to a file that didn't exist** — social previews on
  WhatsApp/LinkedIn/Twitter/Facebook were silently broken. Generated a real
  branded `public/og-image.jpg` (1200×630) matching the site's dark/teal
  theme.
- **No favicon at all.** Added `public/favicon.svg`, `favicon-32.png`, and
  `apple-touch-icon.png`, and referenced them in `index.html`.
- **Profile photo was 1.6MB** for a 941×1672 image displayed small on the
  page — a real Core Web Vitals / LCP risk on mobile. Recompressed it (and
  every other image asset) with Pillow; profile photo is now ~105KB at the
  same effective display size. All other images were resized to sensible
  max dimensions and re-compressed too.
- **EmailJS keys were committed in `.env`.** Added `.gitignore` (ignoring
  `.env`, `node_modules`, `dist`) and `.env.example` with placeholder values.
  **Action needed from you:** the real keys are already in your git history,
  so `.gitignore` alone won't remove them — rotate the EmailJS keys in your
  EmailJS dashboard and set the new ones as environment variables in
  Vercel's project settings instead of committing `.env`.
- Added basic security/caching headers in `vercel.json` and long-lived cache
  headers for hashed asset files.
- `robots` meta tag now explicit (`index, follow`) on every page, and the
  project "not found" state now sets `noindex` so it can't get indexed.

## New files

- `src/config/site.js` — single source of truth for the site URL, name, and
  social links.
- `src/hooks/useDocumentHead.js` — keeps `<title>`, meta tags, canonical
  link, and JSON-LD in sync on client-side route changes (the prerendered
  HTML handles first-load/crawler SEO; this handles it for real users
  navigating without a full reload).
- `src/data/projects.json` — plain-data version of the project list (no
  image imports), shared by both the React app and the Node build script.
- `scripts/generate-static-pages.mjs` — postbuild script that prerenders
  per-project HTML shells and generates `sitemap.xml`.
